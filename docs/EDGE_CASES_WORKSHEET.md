# ورقة عمل الحالات الحافة (Edge Cases Worksheet) - منصة (إسألني) التعليمية

تحدد هذه الوثيقة السيناريوهات التقنية غير التقليدية التي قد تواجه الطالب أو المعلم أثناء استخدام منصة **(إسألني)**، مع وضع حلول هندسية لضمان استقرار العملية التعليمية.

## 1. استقرار الاتصال والجلسات الحية (Connectivity & Live Sessions)

| الحالة الحافة (Edge Case) | التأثير التقني | الحل الهندسي المقترح (Engineering Mitigation) |
| :--- | :--- | :--- |
| انقطاع الإنترنت المفاجئ أثناء مكالمة فيديو تعليمية. | فقدان بيانات الإشارة (Signaling Data) وتوقف الشرح. | تنفيذ آلية **ICE Connection State Monitoring** لإعادة الاتصال التلقائي (Auto-Reconnect) فور استعادة الشبكة دون الحاجة لإعادة طلب المكالمة. |
| تبديل الطالب للشبكة (من Wi-Fi إلى 4G) أثناء رفع ملف تعليمي ضخم. | فشل عملية الرفع (Upload Failure). | استخدام تقنية **Chunked Uploading** مع دعم الاستئناف (Resume) من النقطة التي توقف عندها الرفع لضمان وصول الملفات والمناهج كاملة. |
| تأخر وصول نبضات القلب (Heartbeat) من خادم الـ Socket. | ظهور المعلم كـ "غير متصل" بينما هو متاح. | رفع مهلة الـ **Connection Timeout** إلى 10 ثوانٍ مع تنفيذ محاولات إعادة اتصال (Exponential Backoff) لتقليل الضغط على الخادم. |

## 2. أمن البيانات والخصوصية التعليمية (Security & Privacy)

| الحالة الحافة (Edge Case) | التأثير التقني | الحل الهندسي المقترح (Engineering Mitigation) |
| :--- | :--- | :--- |
| محاولة فك تشفير رسالة تعليمية قديمة بمفتاح RSA منتهي الصلاحية. | عدم القدرة على قراءة الإجابة السابقة. | تنفيذ نظام **Key Rotation Management** يربط كل رسالة بنسخة المفتاح المستخدمة وقتها، مع تخزين المفاتيح بشكل آمن في الـ KeyStore المحلي. |
| استقبال ملف تعليمي بصيغة غير مدعومة أو تالفة. | انهيار التطبيق (App Crash). | إضافة طبقة **MIME Type Validation** قبل بدء عملية المعالجة، مع وضع استثناءات (Try-Catch) لعرض رسالة خطأ صديقة للمستخدم. |

## 3. الأداء واستمرارية الخدمة (Performance & Continuity)

| الحالة الحافة (Edge Case) | التأثير التقني | الحل الهندسي المقترح (Engineering Mitigation) |
| :--- | :--- | :--- |
| قيام نظام أندرويد بقتل خدمة الخلفية أثناء انتظار الطالب لإجابة عاجلة. | عدم وصول إشعار الإجابة في الوقت الفعلي. | استخدام **Foreground Service** مع أيقونة ثابتة في شريط التنبيهات، وطلب إذن `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` لضمان بقاء الطالب متصلاً. |
