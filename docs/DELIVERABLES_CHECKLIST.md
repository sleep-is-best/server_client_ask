# قائمة تسليمات المشروع (Project Deliverables Checklist)
## المشروع: منصة (إسألني - Ask Me) التعليمية

تمثل هذه القائمة خارطة الطريق الهندسية لمراحل تسليم مشروع منصة **(إسألني)**، وهي مصممة لضمان اكتمال كافة المكونات البرمجية والتوثيقية وفقاً لدورة حياة تطوير البرمجيات (SDLC).

## المرحلة 1: التأسيس ومعمارية الأمان (Foundation & Security Architecture)
- [x] **تجهيز بيئة التطوير:** إعداد بيئة Flutter و Node.js وإعداد خادم Socket.io Signaling.
- [x] **بناء طبقة التشفير الهجين:** تنفيذ فئة `CryptoHelper` لدعم تشفير AES-256 (للبيانات) و RSA (لتبادل المفاتيح التعليمية).
- [x] **تصميم قاعدة البيانات المحلية:** تنفيذ جداول `SQLite` باستخدام مكتبة `sqflite` لتخزين الأرشيف التعليمي.
- [x] **إثبات مفهوم الاتصال (PoC):** نجاح تبادل أول رسالة تعليمية مشفرة بين طالب ومعلم عبر الـ Socket.

## المرحلة 2: المراسلة والتبادل المعرفي (Educational Messaging)
- [x] **محرك الحالة (Presence Engine):** تنفيذ مؤشرات "متصل الآن" و "يكتب شرحاً الآن..." لتعزيز التفاعل.
- [x] **نظام تتبع الرسائل:** تنفيذ حالات (Sent, Delivered, Read) لضمان متابعة الطالب لوصول استفساراته.
- [x] **تبادل الوسائط التعليمية:** دعم رفع وتشغيل المقاطع الصوتية، الصور التوضيحية، وملفات الـ PDF المشفرة.
- [x] **مشاركة الموقع التعليمي:** ميزة مشاركة الموقع الجغرافي للقاءات التعليمية الواقعية.
- [x] **الأرشفة والبحث:** تنفيذ محرك بحث داخلي في قاعدة البيانات المحلية للوصول السريع للمعلومات.

## المرحلة 3: الاتصال المرئي والصوتي المباشر (Virtual Classroom - WebRTC)
- [x] **تنسيق الإشارات (Signaling):** تنفيذ تبادل الـ Offers/Answers والـ ICE Candidates عبر السيرفر.
- [x] **المكالمات الصوتية (P2P):** إطلاق ميزة الشرح الصوتي المباشر بجودة عالية وزمن وصول منخفض.
- [x] **المكالمات المرئية (HD Video):** تنفيذ ميزة "الفصل الافتراضي" مع دعم تبديل الكاميرا وكتم الصوت.
- [x] **خدمة الخلفية المستمرة:** دمج `flutter_background_service` لضمان استقبال اتصالات المعلمين حتى لو كان التطبيق مغلقاً.

## المرحلة 4: تحسين تجربة المستخدم والهوية البصرية (Educational UI/UX)
- [x] **الهوية البصرية التعليمية:** تطبيق نمط التصميم (ذهبي/أسود/فضي) الذي يعبر عن قيمة العلم.
- [x] **دعم اللغة العربية (RTL):** التأكد من توافق كافة الواجهات مع اتجاه الكتابة العربي والخطوط التعليمية.
- [x] **مزامنة جهات الاتصال:** ميزة التعرف التلقائي على المعلمين والطلاب المسجلين في قائمة الهاتف.
- [x] **تأثيرات الواجهة (Animations):** إضافة انتقالات سلسة تعزز من تركيز المتعلم وتقلل التشتت.

## المرحلة 5: التوثيق الهندسي والتدقيق (Documentation & Quality Audit)
- [x] **حزمة المستندات الهندسية:** إكمال ملفات SRS, Project Brief, Edge Cases باللغتين العربية والإنجليزية.
- [x] **أدلة التطوير:** إعداد ملفات Contributing و Git Workflow للمطورين الجدد.
- [ ] **التدقيق الأمني (Security Audit):** فحص مسارات فك التشفير والتأكد من عدم وجود تسريب للمفاتيح (Keys Leakage).
- [ ] **اختبارات القبول النهائية (UAT):** تجربة المنصة من قبل مجموعة من الطلاب والمعلمين الحقيقيين.
- [ ] **تجهيز النشر (Deployment):** إعداد ملفات APK/Bundle وتجهيز بيانات المتاجر (Play Store / App Store).
