# server_client_ask

مشروع تجريبي لمنصة تعليمية وتواصل فوري مبنية باستخدام Flutter وDart.

## الحالة

هذا المستودع للتجربة وترتيب الملفات حالياً، وليس نسخة جاهزة للإنتاج.

## المزايا التجريبية

- واجهات Flutter باللغة العربية.
- أسئلة وإجابات ولوحة متصدرين.
- محادثات فورية باستخدام Socket.IO.
- مكالمات صوتية ومرئية باستخدام WebRTC.
- تخزين محلي للبيانات باستخدام SQLite.
- إشعارات وخدمة تعمل في الخلفية.
- شاشات للملف الشخصي، المحادثات، المكالمات، المقاطع، والإدارة.

## هيكل المشروع

```text
lib/
├── main.dart                 # نقطة تشغيل التطبيق
├── config.dart               # إعدادات الاتصال
├── models/                   # نماذج البيانات
├── services/                 # خدمات API وقاعدة البيانات والإشعارات
├── screens/                  # شاشات التطبيق
├── widgets/                  # المكونات القابلة لإعادة الاستخدام
└── utils/                    # الثيم، التشفير، ومعالجة الأخطاء
```

> قد تكون بعض الملفات في جذر المستودع حالياً أثناء مرحلة إعادة التنظيم.

## التشغيل

بعد تجهيز مشروع Flutter وإضافة ملف `pubspec.yaml` والاعتماديات المطلوبة:

```bash
flutter pub get
flutter run
```

## الإعدادات

عدّل إعدادات الاتصال بالخادم في `config.dart` بما يناسب بيئة الاختبار لديك، بما في ذلك عنوان الخادم ومنافذ الاتصال.

## ملاحظات

- المشروع تجريبي وقد يحتوي على تغييرات غير مكتملة.
- لا تستخدم الإعدادات الحالية في بيئة إنتاج.
- يجب نقل أي مفاتيح أو بيانات سرية إلى آلية آمنة قبل النشر.
