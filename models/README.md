# Models

هذا المجلد يحتوي على النماذج الأساسية لبيانات التطبيق، والتي تمثل الكيانات الرئيسية التي يتعامل معها النظام.

## ما الذي تم إنجازه

تم بناء هيكل البيانات الأساسي للمشروع من خلال إنشاء نماذج تمثل:

- الرسائل والمحادثات
- الأسئلة
- الإجابات
- المواد التعليمية
- الريلز
- الرسائل العامة

## الملفات الرئيسية

### `chat_message.dart`
يمثل نموذج رسالة الدردشة بين مستخدمين. يحتوي على:
- هوية المرسل والمستقبل
- نص الرسالة
- الوقت والتاريخ
- نوع الرسالة (نص، صورة، ملف، صوت، موقع)
- رابط الوسائط
- اسم الملف
- المسار المحلي
- حالة الرسالة
- معلومات الحذف التلقائي

### `chat_message.g.dart`
ملف تم إنشاؤه تلقائيًا لدعم قاعدة البيانات المحلية باستخدام Isar.
يساعد في:
- تخزين الرسائل محليًا
- استرجاع البيانات بسرعة
- تحديثها وحذفها بسهولة

### ملفات النماذج الأخرى
- `question.dart`: يمثل السؤال الذي يطرحه الطالب
- `answer.dart`: يمثل إجابة على سؤال محدد
- `educational_material.dart`: يمثل مادة تعليمية أو ملف تعليمي
- `reel.dart`: يمثل فيديو قصير أو Reel
- `message.dart`: يمثل رسالة عامة داخل التطبيق

## أهمية هذا المجلد

هذا المجلد يعتبر الأساس لبيانات التطبيق، لأنه يحدد البيانات التي سيتم تخزينها ومعالجتها في التطبيق. بدون هذه النماذج، لا يمكن تنظيم الرسائل، المواد، الأسئلة، أو المحتوى المرئي بشكل صحيح.

## الخلاصة

تم إعداد البنية الأساسية للبيانات في المشروع بشكل منظم ومناسب للتطوير المستقبلي، مع إمكانية توسيع كل نموذج لاحقًا عند إضافة ميزات جديدة.
