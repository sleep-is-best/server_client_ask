# Services

هذا المجلد يحتوي على الخدمات الأساسية للمشروع، والتي تدير تفاعل التطبيق مع البيانات والخادم والوظائف المساندة.

## ما الذي تم إنجازه

تم إعداد طبقة الخدمات الأساسية لتغطي:

- الاتصال مع الخادم عبر API
- إدارة البيانات المحلية
- التخزين المؤقت
- الإشعارات
- الدردشة المباشرة
- التعامل مع الصوت والفيديو
- إدارة جهات الاتصال

## الملفات الرئيسية

### `api_service.dart`
تمثل هذه الخدمة الطبقة الرئيسية للتواصل مع الخادم. تشمل الوظائف الأساسية:
- تسجيل المستخدم وتسجيل الدخول
- تحديث الملف الشخصي
- جلب بيانات الطالب
- رفع الملفات والصور
- جلب الأسئلة والإجابات
- جلب المواد التعليمية
- إدارة الريلز
- متابعة أو حظر المستخدمين
- الإدارة والإبلاغ والـ Admin

هذا الملف يعمل كواجهة موحدة بين التطبيق والخادم، ويسهل التعامل مع جميع الطلبات.

### `database_service.dart`
خدمة لإدارة قاعدة البيانات المحلية داخل التطبيق، وتستخدم لتخزين البيانات مثل الرسائل والمحتوى المحلي.

### `cache_service.dart`
خدمة لتخزين البيانات المؤقتة لتحسين الأداء وتقليل الحاجة إلى طلبات متكررة من الخادم.

### `notification_service.dart`
خدمة لإدارة الإشعارات داخل التطبيق، مثل تنبيهات الرسائل أو التحديثات.

### `socket_service.dart`
خدمة للتواصل المباشر في الوقت الحقيقي عبر Socket، وتستخدم في الرسائل الفورية والتحديثات الحية.

### `webrtc_service.dart`
خدمة لدعم مكالمات الصوت والفيديو باستخدام WebRTC.

### `audio_service.dart`
خدمة للتعامل مع الصوت، مثل التسجيل أو التشغيل.

### `contact_service.dart`
خدمة لإدارة جهات الاتصال داخل التطبيق.

## أهمية هذا المجلد

هذا المجلد يمثل المحرك الرئيسي للتطبيق، لأنه يربط واجهة المستخدم مع الخادم والبيانات والوظائف المساندة. بفضل هذه الخدمات، يصبح التطبيق قادرًا على:

- التواصل مع الخادم
- حفظ البيانات محليًا
- إرسال الإشعارات
- إدارة الدردشة المباشرة
- التعامل مع الصوت والفيديو
- تحسين الأداء وتجربة المستخدم

## الخلاصة

تم بناء البنية الأساسية للخدمات في المشروع بشكل منظم، مع دعم وظائف ضرورية للتطبيق، وجاهز للتطوير لاحقًا لإضافة مزايا أكثر تعقيدًا وواجهات جديدة.
